# Текст под озвучку

Темп ~2,5 слова/сек. `/` — короткая пауза, `//` — длинная пауза, **жирный** — логическое ударение.

## Версия 15 сек (35 слов)

| Время | Текст |
|---|---|
| 00:00–00:03 | Я больше **не плачу** / монтажёрам и сценаристам. // |
| 00:03–00:10 | Сценарий, / озвучку / и звук для этого ролика / собрал **Claude**. / Одна команда — / вся рутина **готова**. // |
| 00:10–00:15 | ИИ не отбирает работу — / он заменяет тех, / кто им **не пользуется**. / Подпишись — / покажу, как настроить. |

## Длинная версия ~22 сек (исходный текст)

| Время | Текст |
|---|---|
| 00:00–00:03 | Я больше **не трачу часы** / на подготовку роликов. // |
| 00:03–00:14 | Этот ролик / от идеи до раскадровки и звука / собрал **Claude**. / Я дал всего **одну команду**, / а всю рутину / он сделал сам / через мой GitHub-шаблон. // |
| 00:14–00:22 | ИИ не отбирает работу. / ИИ заменяет тех, / кто им **не пользуется**. // Хочешь узнать, / как настроить такого помощника? / **Подписывайся**. |

Подача: уверенно, чуть быстрее обычного, без «продающей» интонации. Хук — на выдохе, как факт.
