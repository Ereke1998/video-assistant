# Стратегия Instagram: блог про ИИ-видео и монтаж (без лица)

Дата: 2026-11-19 · Старт: 1133 подписчика · Цель: рост подписчиков и охвата · Темп: 3–4 публикации в неделю · Языки: RU + KZ

## 1. Позиционирование

**Ниша:** «ИИ для создания видео — просто и по-нашему».
Полезные короткие ролики о том, как делать видео с помощью ИИ (Claude, генерация видео, монтаж, озвучка), плюс интересные факты про ИИ.

**Почему это работает:**
- Тема на подъёме, а на казахском языке почти нет такого контента — это твоё преимущество.
- Ролики «как сделать» и «сохрани, пригодится» набирают сохранения и пересылки — главные сигналы алгоритма.
- Ты сам учишься → контент «учусь вместе с вами» честный и не требует быть экспертом.

**Формула bio (пример):**
```
ИИ-видео без лица 🎬🤖
Монтаж, озвучка, Claude — показываю как
Қазақша + на русском
👇 Бесплатный гайд / промпты
```

## 2. Старый аккаунт — что делать

Не создавай новый — подписчики и возраст аккаунта полезны. Делай перезапуск:

1. **Архивируй (не удаляй)** старые посты, не связанные с темой. Архив скрывает их из сетки, удаление не «сбрасывает» алгоритм.
2. **Смени имя профиля, аватар и bio** под новую тему (ник можно оставить, если он нейтральный).
3. **Переключись на профессиональный аккаунт** (Автор), если ещё не сделано — нужна статистика.
4. **Прогрев 5–7 дней до первого Reels:** смотри и комментируй 10–15 аккаунтов в нише ИИ/монтажа в день, ставь сторис 1–2 раза в день.
5. **Первые 2–3 недели охват будет низким** — это нормально: старые подписчики не реагируют, алгоритм заново собирает данные.
6. **Анонс в сторис:** «Перезапускаю блог: теперь здесь про ИИ-видео. Оставайтесь 👇» + опрос.

## 3. Формат «без лица», который не режут

ИИ-контент сам по себе не штрафуется. Режут **неоригинальное**: репосты, чужие нарезки, однотипный массовый контент, ролики только с ИИ-аватаром.

| ✅ Делать | ❌ Избегать |
|---|---|
| Запись своего экрана (процесс работы) | Чужие видео / нарезки |
| Свои ИИ-генерации + твоя озвучка | Статичная картинка + голос |
| Свой голос или клон своего голоса (ElevenLabs) | ИИ-аватар «говорящая голова» как основной формат |
| Движение в кадре каждые 1–2 сек | Водяные знаки TikTok/CapCut |
| Метка «ИИ», если она нужна (охват не режет) | Одинаковые шаблонные ролики подряд |

**Хронометраж:** 15–35 сек для охвата, до 60 сек для туториалов. Не длиннее 3 минут.

## 4. Языки

- **Основной язык охвата — RU** (больше аудитория), **KZ — фишка и отличие**.
- Вариант, который рекомендую: **одно видео — две версии** (озвучка RU и KZ), публиковать по очереди с разницей 2–3 дня. Двойной контент без двойной работы.
- Через **Пробные Reels (Trial Reels)** проверяй, какая версия лучше заходит у неподписчиков.
- Субтитры всегда — на языке озвучки.

## 5. Рубрики

| Рубрика | Формат | Цель |
|---|---|---|
| **«ИИ за 30 секунд»** — один инструмент / приём | Reels, экран + озвучка | Сохранения |
| **«Факт, о котором ты не знал»** — интересное про ИИ | Reels, ИИ-визуал + озвучка | Пересылки, охват |
| **«До / После»** — сырое видео → смонтированное с ИИ | Reels | Пересылки, «вау» |
| **«Промпт недели»** — готовый промпт для видео | Карусель | Сохранения |
| **«Учусь вместе с вами»** — честный опыт, ошибки | Reels / сторис | Доверие, комментарии |

## 6. Неделя (3–4 публикации)

| День | Публикация |
|---|---|
| Пн | Reels «ИИ за 30 секунд» (RU) |
| Ср | Reels «Факт» (KZ версия прошлого или новый) |
| Пт | Карусель «Промпт недели» |
| Вс (по возможности) | Reels «До / После» |
| Ежедневно | 1–3 сторис: процесс, опросы, «что сделать следующим?» |

## 7. Правила каждого ролика

1. **Хук за 1–2 сек** — текстом на экране + голосом.
2. **Одна мысль в ролике.**
3. **Призыв к пересылке/сохранению:** «Отправь тому, кто монтирует руками» / «Сохрани, чтобы не потерять».
4. **Вопрос в конце** → комментарии.
5. **Обложка** с крупным текстом — сетка должна выглядеть единой.

## 8. Метрики (смотри раз в неделю в Insights)

| Метрика | Ориентир |
|---|---|
| Досмотр 3 сек (удержание хука) | > 60% |
| Средний % просмотра | > 50% |
| Пересылки + сохранения на 1000 охвата | растут неделя к неделе |
| Охват неподписчиков | > 60% охвата Reels |

Через 4 недели — разбор: какие рубрики и какой язык работают лучше → удваиваем их.
