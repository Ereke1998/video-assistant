# Озвучка — GTA 6 вышла

`/` — короткая пауза, `//` — длинная. **Жирным** — ударение.

## RU (~70 слов · ~32 сек)

1. GTA 6 вышла **сегодня** — / и уже побила **рекорд**. //
2. **Девяносто девять** из ста на Metacritic. / Так высоко оценивали только **одну** игру в истории — / Зельду девяносто восьмого года. //
3. IGN, / GameSpot, / Game Informer — / **десять из десяти**. / Все рецензии — **положительные**. //
4. Игроки в восторге от **графики** и **вождения**. / Кто-то даже взял **отгул**, / чтобы поиграть. //
5. Но есть и **минусы**: / на консолях — тридцать кадров в секунду, / онлайна на старте **нет**, / а кому-то не зашло радио. //
6. Ждали **тринадцать лет** — / и, похоже, **дождались**. //
7. А ты уже играешь? / Пиши в комменты.

## KZ (~60 сөз · ~32 сек)

1. GTA 6 **бүгін** шықты — / және бірден **рекорд** жаңартты. //
2. Metacritic-те жүзден **тоқсан тоғыз**. / Тарихта мұндай бағаны тек **бір** ойын алған — / тоқсан сегізінші жылғы Зельда. //
3. IGN, / GameSpot, / Game Informer — / **оннан он**. / Барлық пікір — **оң**. //
4. Ойыншылар **графика** мен **көлік жүргізуге** тәнті. / Біреулер ойнау үшін тіпті **демалыс** алып жатыр. //
5. Бірақ **кемшіліктері** де бар: / консольде — секундына отыз кадр, / басында **онлайн жоқ**, / ал кейбіреулерге радио ұнамады. //
6. **Он үш жыл** күттік — / сірә, **күткенге** тұрды. //
7. Сен ойнап жатырсың ба? / Пікірге жаз.

> Для ИИ-голоса: «GTA» → «Джи-Ти-Эй», «IGN» → «Ай-Джи-Эн», «Metacritic» → «Метакритик».
