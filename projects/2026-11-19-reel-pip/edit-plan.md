# Монтажный план — reel-pip (18 с, 1080×1920, 30 fps)

Исходник: обзор квартиры в черновой отделке, 3:23, 576×1024 (апскейл ×1.875, lanczos + unsharp).

| Ролик | Исходник | Кадр | Обработка |
|---|---|---|---|
| 00:00–03:00 | 2:27.5 | Вид из окна: небо, город, стройплощадка | заголовок «ЧЕРНОВАЯ ОТДЕЛКА», холодный «сырой» грейд |
| 03:00–05:00 | 1:12.5 | Вход в комнату, героиня уходит вглубь | жёсткая склейка |
| 05:00–07:00 | 2:08 | Коридор | жёсткая склейка |
| 07:00–09:00 | 0:18 | Общий план большой комнаты | жёсткая склейка |
| 09:00–12:00 | 2:23 | Эркер → окно | наезд 1.0→1.18, вспышка в белое 11.85–12.0 |
| 12:00–18:00 | 3:04 | Общий план, героиня в комнате | выход из белого 0.25 с, нейтральный грейд |
| 12:00 | — | Подпись «Сюда — готовый интерьер ↑» | под вставкой справа, y=856, подложка 50 % |
| 12:50–18:00 | ИИ-клип | **PiP справа сверху** 384×682 @ x=642 y=141 | сейчас ПРЕВЬЮ (тот же план, тёплый грейд) |

Сборка: `build_base.sh` → `compose_pip.sh 12.5:<клип>` → `build_sound.sh` → `reel_pip_final.mp4`.

## Ограничения исходника
- В исходнике водяной знак TikTok и ник автора. Для публикации нужен оригинал без водяного знака (и права на видео).
- Звук исходника — сплошная речь в петличку. По ТЗ голоса нет, поэтому атмосфера стройки синтезирована.
- Дрона в исходнике нет: «облёт» 3–9 с заменён проходом по комнатам, гул дрона в звуке оставлен как атмосфера (можно убрать).
