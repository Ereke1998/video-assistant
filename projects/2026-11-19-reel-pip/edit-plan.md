# Монтажный план — reel-pip «ДО / ПОСЛЕ» (18 с, 1080×1920, 30 fps)

Исходник: обзор квартиры в черновой отделке (3:23, 576×1024, апскейл ×1.875 lanczos + unsharp).
«После»: картинки заказчика `after/img1–img5.jpg`, выровненные по кадрам исходника скриптом `align_after.py`
(момент совпадения, масштаб, сдвиг → `after/after_N.png` 1080×1920, `after/align.json`),
затем анимированы `animate_after.py` → `after/anim_N.mp4`: интерьер следует за камерой (гомография по фону),
героиня — живая из исходника (HOG → CSRT-трекер → GrabCut), её неподвижная копия на картинке стёрта (inpaint).
Планы и тайминги — **`shots.conf`**. Раскадровка — `storyboard.png`.

## Схема плана с проявлением
| Внутри плана | Картинка | Звук |
|---|---|---|
| 0.0–1.5 с | **ДО**: исходник играет, холодный «сырой» грейд | голос + стройка |
| 1.5–2.2 с | шторка слева направо (мягкий край 18 %) — интерьер ложится прямо на движущийся кадр | whoosh; стройка глушится |
| 2.2 с → конец | **ПОСЛЕ** движется дальше: камера и героиня из исходника, интерьер «приклеен» к камере | «динь», тёплый пад + «воздух зала» |

Весь ролик в кропе 106 % — прячет края, куда картинка не дотягивается при движении камеры.

## Сборка
```bash
python3 -I align_after.py /tmp/work/src/src.mp4 after after/img1.jpg:129.2 ...   # только при новых картинках
python3 -I animate_after.py /tmp/work/src/src.mp4 after 1.7 1 2 3   # (+ «0.9 4», «2.1 5»)
bash build_video.sh     # MODE=fade — наплыв; ZOOM=0.06 — наезд; PRE/REVEAL_DUR/HOLD — в shots.conf
bash build_sound.sh     # → /tmp/work/out/reel_pip_final.mp4
```

## Ограничения
- Движение «после» — монтажное (трекинг + вырезание героини), не генерация: по краям при сильном движении камеры
  бывает лёгкое «растяжение» (план 2, левый край), контур героини местами мягкий/неточный (руки в коридоре).
  Идеал — клипы image-to-video из этих картинок (Kling / Runway); build_video.sh примет и их (`after/anim_N.mp4`).
- Водяной знак TikTok в «ДО» (исходник). На «ПОСЛЕ» его нет.
- Речь в планах по 2–3 с обрывается на склейках.
