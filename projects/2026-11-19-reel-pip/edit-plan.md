# Монтажный план — reel-pip «ДО / ПОСЛЕ» (18 с, 1080×1920, 30 fps)

Исходник: обзор квартиры в черновой отделке (3:23, 576×1024, апскейл ×1.875 lanczos + unsharp).
Стиль «после»: видео-референс интерьера (тёплый минимализм, грейж) → `ai-input/prompt.md`.
Список планов и тайминги — **`shots.conf`** (общий для всех скриптов).

## Схема каждого плана (3 с)
| Внутри плана | Картинка | Звук |
|---|---|---|
| 0.0–1.0 с | **ДО**: исходник, холодный «сырой» грейд | голос + стройка (ветер, город, молотки) |
| 1.0–1.7 с | шторка слева направо (мягкий край 18 %) — интерьер ложится прямо на кадр | whoosh 500→3500→1000 Гц |
| 1.7–3.0 с | **ПОСЛЕ**: ИИ-клип того же плана на весь кадр | «динь» в 1.7 с, стройка глушится LP 1.5 кГц −6 дБ, тёплый пад + «воздух зала» |

## Планы
| # | Ролик | Исходник | Кадр |
|---|---|---|---|
| 1 | 00:00–03:00 | 2:27.5 | Вид из окна + заголовок «ДО / ПОСЛЕ» (поверх всех слоёв) |
| 2 | 03:00–06:00 | 1:12.5 | Вход в комнату |
| 3 | 06:00–09:00 | 2:08 | Коридор |
| 4 | 09:00–12:00 | 0:18 | Общий план большой комнаты |
| 5 | 12:00–15:00 | 2:23 | Эркер с окном |
| 6 | 15:00–18:00 | 3:04 | Общий план у эркера |

Склейки между планами — жёсткие (раньше были наезд и белая вспышка; убраны, т.к. «после» должно совпадать с кадром 1:1).
Подпись «Сюда — готовый интерьер» убрана (смысл теперь в «ДО / ПОСЛЕ»), включается обратно в `compose_reveal.sh`.

## Сборка
```bash
bash build_base.sh        # «ДО», синхронный звук, ИИ-набор, превью «после»
# готовые ИИ-клипы → /tmp/work/ai_output/shot1.mp4 … shot6.mp4
bash compose_reveal.sh    # MODE=fade — наплыв вместо шторки; REVEAL_AT / REVEAL_DUR — в shots.conf
bash build_sound.sh       # → /tmp/work/out/reel_pip_final.mp4
```

## Ограничения исходника
- Водяной знак TikTok и ник автора в исходнике (и в референсе интерьера) — для публикации нужны оригиналы без них и права.
- Речь в планах по 3 с обрывается на склейках — это монтажная речь, а не цельная фраза.
- План 1 — вид на улицу: «после» там — только оформленное окно (шторы, подоконник), город остаётся.
