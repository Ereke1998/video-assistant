# PRIME IT — раскадровка v3 (на согласование)

Стиль собран из двух референсов: тёмный неон из видео 2 и инфографика из видео 1. Основа — 2D motion-графика, 3D-ноутбук-голограмма появляется как акцент.
Формат: 1080×1920, 60 fps, 32 с. Тексты субтитров и точки SFX — из ТЗ, без изменений.

## Стиль

| Элемент | Решение |
|---|---|
| Фон | почти чёрный `#0B0B10`, из центра расходятся лучи света (sunburst); цвет лучей задаёт сцена; по краям мерцают звёздочки ✦ |
| Шапка (из видео 1) | сверху, ниже безопасной зоны: слева «PRIME IT», справа «РЕМОНТ НОУТБУКОВ», под ними тонкая градиентная линия-прогресс ролика |
| Иконки | неоновые линейные (вентилятор, чип, пыль, огонь, щит, самолётик директа…). Сначала прорисовываются линией, потом загораются |
| Карточки | скруглённые неоновые рамки с крупной цифрой внутри (как карточка «99» в видео 2) |
| Плашки | тёмная «таблетка» с неоновой обводкой, текст ЗАГЛАВНЫМИ (например, «#1 ПЕРЕГРЕВ», «ДО / ПОСЛЕ») |
| Инфографика (из видео 1) | столбики «до/после», заштрихованный столбик-диапазон, счётчики, график FPS |
| 3D-акцент | неоновый ноутбук-голограмма из v2: хук, чистка, финал |
| Цвета сцен | проблема — оранжевый `#FF6A00` и красный `#FF2D3A`; решение и бренд — синий `#2F6BFF` и голубой `#3DD8FF`; цифры белые с цветным свечением |
| Шрифт | Oswald Bold: субтитры, цифры, плашки |
| Субтитры | 2–3 слова на экране, ВСЁ ЗАГЛАВНЫМИ, ~110 px, белые; ключевое слово окрашено в цвет сцены; по центру на ~70 % высоты (y≈1340); появляются фразой с pop-in |
| Переходы | быстрый зум и вспышка в цвете следующей сцены, у элементов — scale-pop и пружина |

> В отличие от ТЗ на экране появятся короткие плашки-подписи: этого требует стиль референсов. Если они не нужны, уберу.
