## Чистовой текст для диктора

> [медленно, устало] Клод… / Клод… / Клод… // [живее, с иронией] У вас тоже вся лента забита этим **Клодом**? //
> [доверительно] Сегодня поговорим о том, / что это **вообще** такое / и **почему** о нём все говорят. //
> [объясняюще] Клод — это **искусственный интеллект**, / который умеет работать с текстами, / анализировать информацию, / писать **код** / и помогать в решении разных задач. //
> [интрига] Но самое **интересное** — / с его помощью можно даже работать над **видеомонтажом**! //
> [деловито] Например, можно дать ему видео эксперта, / и он поможет разобрать **речь**, / подобрать подходящие **вставки**, **субтитры** / и даже подготовить **план монтажа**. //
> [увереннее] А с помощью **Клод Код** / можно пойти **ещё дальше** / и автоматизировать некоторые процессы. //
> [тепло] В следующих видео покажу на **реальном примере**, / как это работает! //
> [дружелюбно] ПодпИсывайтесь на **Екасымофф**, / чтобы не пропустить!

## Произношение
- ekasymoff → **Екасымофф** (так написано для синтеза; если читается неверно — поправить в `timeline.config.js → finale.vo.parts[1].tts`)
- Claude → **Клод** (одним слогом, «о» долгое), Claude Code → **Клод Код**
- автоматизИровать, информАцию, искУсственный

## Перезапись своим голосом
Пиши каждую фразу отдельным файлом и клади в `render/build/vo/<scene>-1.fit.wav` (`hook-1`, `hook-2`, `finale-2`, `intro`, `what`, `twist`, `example`, `code`, `finale`). Старт фразы — поле `at` в `timeline.config.js`. Либо замени `voiceId` в `audio.config.js` и запусти `npm run tts -- --force`.
