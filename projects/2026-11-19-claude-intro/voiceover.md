# Озвучка: Claude — что это и почему о нём все говорят
Язык: RU · Длительность ролика: 37 с · Чистая речь: 33,2 с · Слов: 100
Тон: живой блогер, удивление в хуке, «раскрытие» на поворот про монтаж, тёплый анонс в конце
Голос: ElevenLabs `eleven_multilingual_v2`, тот же мужской русский голос, что и в прошлом ролике, speed 1.12

## Текст не сокращался

Каждая фраза влезла в окно своей сцены **без ускорения** (tempo 1,0). Сцены выставлены под реальную длину фраз, поэтому ролик 37 с, а не 40.
Для синтеза латиница заменена кириллицей: Claude → «Клод», Claude Code → «Клод Код». На экране и в субтитрах — латиницей.

## Произношение
- Claude → **Клод** (одним слогом, «о» долгое), Claude Code → **Клод Код**
- автоматизИровать, информАцию, искУсственный

## Перезапись своим голосом
Пиши каждую фразу отдельным файлом и клади в `render/build/vo/<scene>-1.fit.wav` (`hook`, `intro`, `what`, `twist`, `example`, `code`, `finale`). Старт фразы — поле `at` в `timeline.config.js`. Либо замени `voiceId` в `audio.config.js` и запусти `npm run tts -- --force`.
