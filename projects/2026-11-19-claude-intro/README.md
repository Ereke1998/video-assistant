# Claude — что это и почему о нём все говорят (40 с, 9:16)

Разбор без лица в кадре, в стиле ролика Kaspi Alaqan: тёмный фон с сеткой, слэм-заголовки, карточки, плашка «● РАЗБОР» с таймером, жёлтые акценты в субтитрах, SFX точно на ударных словах.
1080×1920 · 30 или 60 fps · ровно 40,0 с · H.264 + AAC · −14 LUFS, true peak −1 dBTP.

## Структура рендер-проекта

Тот же движок, что в прошлом ролике: `config/` (всё редактируемое без кода) → `src/scenes/` (7 сцен) → `scripts/` (TTS, заглушки звука, субтитры, рендер Canvas → Playwright → ffmpeg, микс). Каждый файл описан комментарием в шапке; команды те же, что в прошлом ролике.

```bash
cd render
npm i && npx playwright install chromium   # один раз
npm run preview        # http://localhost:5173 (?safe — безопасные зоны)
npm run build          # TTS (из кэша) → заглушки → субтитры → рендер 30 fps → микс → out/*.mp4
npm run build:60       # то же, 60 fps
npm run stills         # контрольные кадры → build/stills/
```

## Как заменить звук

1. Свой трек → `render/assets/music/bg-track.mp3` (12%, дакинг под голос, стоп перед «ВИДЕОМОНТАЖ!»).
2. SFX: замени файлы в `render/assets/sfx/` (`impact-in.wav`, `glitch.wav`, `whoosh.wav`, `pop.wav`, `ding.wav`, `notify.wav`, `typing.wav`, `riser.wav`).
3. `npm run mix` — пересборка звука без перерендера видео.

## Важно перед публикацией

- Логотип Claude/Anthropic не используется: вместо него нейтральный «ИИ-чип» с надписью AI. Название — только текстом.
- Заголовки постов в ленте (сцена 1) и команда в терминале (сцена 6) — иллюстративные, правятся в `timeline.config.js`.
- Звук-заглушки синтетические: перед публикацией замени лицензионными SFX и треком.
