# Озвучка — Выпуск #1

Темп: RU ~2,3 слова/сек, KZ ~2 слова/сек. `/` — короткая пауза, `//` — длинная. **Жирным** — логическое ударение.

## RU (~75 слов · ~32 сек)

1. Я попросил **ИИ** / спасти мой блог. //
2. Аккаунт **старый**, / год ничего не выкладывал. / Тысяча подписчиков — / и **тишина**. //
3. Я написал Claude: / найди **тренды** / и скажи, что делать. //
4. Через пару минут — / **готовая стратегия**. / Ниша, рубрики, / план на месяц / и хуки для каждого ролика. //
5. Главное, что я понял: / Instagram сейчас **режет охваты** за чужой контент. / Нужно **своё**. //
6. Поэтому начинаю заново — / и учусь **вместе с вами**. //
7. Это выпуск номер **один**. / Подпишись — / проверим, сработает ли план.

## KZ (~65 сөз · ~33 сек)

1. Блогымды құтқаруды / **жасанды интеллекттен** сұрадым. //
2. Аккаунт **ескі**, / бір жыл бойы ештеңе салмадым. / Мыңнан астам жазылушы — / бірақ **тыныштық**. //
3. Claude-қа жаздым: / **трендтерді** тауып, / не істеу керегін айт. //
4. Бірнеше минуттан кейін — / **дайын стратегия**. / Тақырып, айдарлар, / бір айлық жоспар / және әр видеоға хук. //
5. Ең басты түсінгенім: / Instagram қазір бөтен контенттің **қамтуын қысқартады**. / **Өз** контентің керек. //
6. Сондықтан қайта бастаймын — / және **сендермен бірге** үйренемін. //
7. Бұл — **бірінші** шығарылым. / Жазылыңыз — / жоспар жұмыс істей ме, көрейік.

> Произношение для ИИ-голоса: «Claude» → «Клод», «ИИ» → «и-и».
