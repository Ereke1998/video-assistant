# Озвучка — «Бір промпт — бір ролик»

`/` — короткая пауза, `//` — длинная. **Жирным** — ударение. `[XX]` — твоё время.
Темп — бодрый, но чёткий (стиль референсов: уверенный рассказчик).

## KZ (основная · ~70 сөз · ~40 сек)

1. **Бір промпт** — / және сексен секундтық видео **дайын**. //
2. Мен оны **монтаждаған жоқпын**. / Бәрін **Claude Code** жасады. //
3. **Бірінші** — / терминалға **бір ғана** сұрау жазамын. //
4. Claude интернеттен фактілерді **өзі** тауып, / сценарий жазады. //
5. Сосын — **дауыс**. / Сценарийден бірден дыбысталады. //
6. Ал ең **қызығы** — графика. / Күн батуы, / неон, / санауыштар — / мұның бәрі **код**. //
7. Соңында — **рендер**. / Субтитр, дыбыс — / бәрі орнында. //
8. Барлығы — / **[XX] минут**. //
9. Келесі видеоны / қандай **тақырыпқа** жасайын? / Пікірге жаз — / ең қызығын **жасаймын**.

## RU (~75 слов · ~38 сек)

1. **Один промпт** — / и видео на восемьдесят секунд **готово**. //
2. Я его **не монтировал**. / Всё сделал **Claude Code**. //
3. **Первое** — / пишу в терминал **один** запрос. //
4. Claude **сам** находит факты в интернете / и пишет сценарий. //
5. Дальше — **голос**. / Озвучка генерируется прямо из сценария. //
6. А самое **интересное** — графика. / Закат, / неон, / счётчики — / всё это **код**. //
7. В конце — **рендер**. / Субтитры, звук — / всё на месте. //
8. Всего — / **[XX] минут**. //
9. На какую **тему** / сделать следующее видео? / Пиши в комментарии — / самую интересную **сделаю**.

> Для ИИ-голоса: «Claude Code» → «Клод Код», «GTA» → «Джи-Ти-Эй».
