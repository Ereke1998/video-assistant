# Озвучка — Making of GTA 6 ролика

`/` — короткая пауза, `//` — длинная. **Жирным** — ударение. `[XX]` — подставь своё время.
Голос — тот же, что в ролике про GTA 6 (узнаваемость стиля).

## RU (~95 слов · ~43 сек)

1. Этот ролик про GTA 6 / я **не монтировал**. //
2. Его сделал ИИ — / **Claude Code**. / Показываю, как. //
3. Шаг **первый**. / Пишу **один** запрос: / найди свежие факты про GTA 6 / и сделай сценарий на семь фактов. //
4. Claude **сам** ищет в интернете / и пишет текст — / с цифрами и датами. //
5. Шаг **третий** — озвучка. / Голос генерируется сразу из сценария. //
6. Самое крутое: / вся графика — это **код**. / Закат, неон, счётчики — / Claude написал всё **сам**. //
7. Шаг **пятый** — рендер. / Субтитры и звук уже на месте. / **Готовое** видео. //
8. На всё ушло / **[XX] минут**. //
9. А ты бы так попробовал? / Пиши в комментариях.

## KZ (~80 сөз · ~42 сек)

1. GTA 6 туралы бұл видеоны / мен **монтаждаған жоқпын**. //
2. Оны ЖИ жасады — / **Claude Code**. / Қалай екенін көрсетемін. //
3. **Бірінші** қадам. / **Бір ғана** сұрау жазамын: / GTA 6 туралы жаңа фактілерді тап / және жеті фактіге сценарий жаса. //
4. Claude интернеттен **өзі** іздейді / және мәтінді жазады — / сандарымен, күндерімен. //
5. **Үшінші** қадам — дыбыстау. / Дауыс сценарийден бірден жасалады. //
6. Ең керемет жері: / бүкіл графика — **код**. / Күн батуы, неон, санауыштар — / бәрін Claude **өзі** жазды. //
7. **Бесінші** қадам — рендер. / Субтитр мен дыбыс дайын. / Видео **дайын**. //
8. Бәріне / **[XX] минут** кетті. //
9. Сен осылай жасап көрер ме едің? / Пікірге жаз.

> Для ИИ-голоса: «Claude Code» → «Клод Код», «GTA» → «Джи-Ти-Эй».
