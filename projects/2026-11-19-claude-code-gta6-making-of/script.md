# «Бір промпт — бір ролик»: как я сделал видео про GTA 6 с Claude Code
**Формат:** Reels 9:16, без лица · **Длительность:** ~40 сек · **Рубрика:** Учусь вместе с вами · **Язык:** KZ основной + RU-версия

## Стиль (по референсам, но свой)

**Берём из референсов:**
- Тёмно-синий/чёрный фон с тонкой сеткой «созвездий» и **нодами-иконками**, соединёнными линиями (workflow ИИ-агента).
- Один акцент — **оранжевый** (свечение, линии, плашки), белый жирный текст.
- Двухуровневый заголовок: сверху мелкий **курсив-засечка оранжевым** («Бір промпт —»), снизу **КРУПНО КАПСОМ** белым.
- Ключевые слова — на **оранжевой плашке**, неверное — **зачёркнуто красным**.
- **Мокапы телефонов** с экранами, чипы-бейджи (✓ Видео дайын), счётчики цифр.

**Своё (чего нет в референсах):**
- **Нет человека в кадре** → центр кадра занимает **окно терминала Claude Code** (моно-шрифт, оранжевый курсор, строки печатаются).
- **Конвейер собирается по ходу ролика:** ноды загораются по одной — `Промпт → Іздеу → Сценарий → Дауыс → Графика → Рендер → Ролик`. К финалу вся цепочка светится.
- **Номера шагов — как в терминале:** `01 / 05`, `02 / 05`…
- **Нет продажи курса** → финал на комментарии: зритель выбирает тему следующего ролика.

**Ноды на фоне:** Промпт · Іздеу · Сценарий · Дауыс · Графика · Рендер · Ролик (иконки в кружках, как в референсе).
