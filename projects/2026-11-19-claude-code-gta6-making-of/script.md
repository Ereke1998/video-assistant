|---|---|---|
| Фон | Ретровейв: закат, силуэт города, пальмы, фиолетовая сетка, звёзды | Тот же фон на всё видео |

**Новое:** записи экрана Claude Code вставляются в неоновую рамку поверх ретровейв-фона (как «экран» в центре кадра).

## Что записать
1. Экран Claude Code: твой промпт → Claude ищет факты → пишет сценарий.
2. Экран: генерация озвучки.
3. Экран: код анимации + превью (фон, неон, счётчики).
4. Экран: рендер / готовый mp4.
5. Готовый ролик про GTA 6 — **без водяного знака TikTok** (исходный файл, а не скачанный из TikTok).
