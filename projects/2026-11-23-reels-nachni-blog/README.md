# Reels «Начни блог» — CGI-кино

Вертикальный ролик 9:16, 1080×1920, ~29 сек. Голос: Gleb (ElevenLabs, eleven_multilingual_v2).

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `project.json` | **Главный файл для правок**: текст фраз, голос, промпты сцен, субтитры, громкость музыки |
| `audio/voiceover.mp3` | Готовая озвучка (послушать) |
| `audio/phrases/` | Озвучка по фразам. Уже оплачена, не удалять |
| `scenes/` | Клипы сцен: `scene_01.mp4` … `scene_06.mp4` |
| `music/` | Положите сюда **один** mp3/wav с фоновой музыкой, и она добавится сама |
| `reels_preview.mp4` | Превью с заглушками вместо сцен, которых ещё нет |
| `reels_final.mp4` | Финальный ролик (появится, когда будут все 6 клипов) |
| `voiceover.md`, `edit-plan.md`, `subtitles.srt` | Таблицы таймингов, монтажный план, субтитры |
| `.env` | Ваши ключи (в GitHub не попадает) |

## Ключи: файл `.env`

1. Скопируйте файл `.env.example` и назовите копию `.env` (с точкой в начале).
2. Откройте `.env` в любом текстовом редакторе.
3. Вставьте ключ после знака `=`, без пробелов и кавычек:
   ```
   ELEVENLABS_API_KEY=sk_ваш_ключ
   ```
   Где взять: elevenlabs.io → раздел Developers → API Keys → Create API Key.

## Как запустить на своём компьютере

Нужны Python 3.10+ и ffmpeg (Mac: `brew install ffmpeg`, Windows: `winget install ffmpeg`).
На Windows вместо `python3` пишите `python`.

```bash
pip install -r requirements.txt     # один раз
python3 1_voiceover.py              # ПЛАТНО: озвучка (спросит подтверждение)
python3 2_plan_scenes.py            # бесплатно: длина сцен под озвучку
node render_animation.js --all      # бесплатно: 3D-сцены кодом → scenes/
python3 3_soundtrack.py             # бесплатно: музыка и звуковые акценты (синтез) → audio/
python3 4_build.py                  # бесплатно: склейка, субтитры, звук → reels_final.mp4
```

## Музыка и звук

- `3_soundtrack.py` сочиняет музыку кодом: тёмный эмбиент, который со слова «Хватит» становится тёплым,
  и акценты (свуши, тиканье, удары на «Час? Два?», REC, глитч). Партитура — в `sound-design.md`.
- **Свой трек:** положите mp3/wav в папку `music/`. Сборка возьмёт его вместо сгенерированного.
- **Громкость:** `project.json` → `music.db_below_voice` (на сколько дБ музыка тише голоса, по умолчанию 14)
  и `sfx.db_below_voice` (акценты, 9). Выключить акценты: `"sfx": {"enabled": false}`.

## Субтитры

Стиль задаётся в `project.json` → `subtitles.style` (сравнение — `subtitle-styles.png`):

| Стиль | Как выглядит |
|---|---|
| `cinema` | широкий Unbounded капсом + ключевые слова курсивной антиквой Playfair с золотым свечением |
| `neon` | неоновое караоке: фраза видна приглушённо, слова «зажигаются» под голос |
| `reference` | как на референсе: жирный строчный Montserrat + ключевые слова на жёлтой плашке |

Слова проявляются в момент, когда их произносят. Шрифты лежат в `fonts/` (бесплатные, лицензия OFL).

```bash
python3 4_build.py                  # после смены стиля — просто пересобрать
```

## Все 6 сцен — 3D-анимация кодом (бесплатно)

Платный видеосервис не нужен: все сцены в стиле CGI-кино нарисованы кодом в файле `animation.html`.

| Сцена | Что на экране |
|---|---|
| 1 | Сверхкрупно экран: листаются чужие сторис → лента замирает, ваш кружок «+» светится жёлтым |
| 2 | 3D-часы по референсу: табло 01:00 на «Час?», 02:00 на «Два?» |
| 3 | Песочные часы: стойки — светящиеся телефоны, песок — иконки соцсетей |
| 4 | Телефон на штатив, «3:00:00» зачёркивается, загорается кольцевая лампа, «15:00», REC |
| 5 | Толпа в холодном свете смотрит в телефоны, одна фигура снимает — её заливает тёплым светом |
| 6 | Screen Time 5h 12m с глитчем, из телефона выскакивает жёлтый пузырь комментария |

- **Посмотреть:** откройте `animation.html` в Chrome, вверху кнопки 1–6 переключают сцены, «↺» (или R) — с начала.
- **Поменять цвета и тексты:** блок `CFG` в начале `animation.html` (например, `screenValue: '5h 12m'`).
- **Записать сцену в видео:** `node render_animation.js --scene 3` → `scenes/scene_03.mp4` (1–3 мин).
  Все сразу: `node render_animation.js --all`.
  Анимация сама берёт время слов из озвучки, поэтому после переозвучки достаточно перезаписать сцены.
  Нужны Node.js и Playwright: `npm install playwright && npx playwright install chromium`.
- Затем `python3 4_build.py` → `reels_final.mp4`.

## Как поменять одну сцену

- **Своим клипом:** положите файл в `scenes/` под именем `scene_04.mp4`, заменив старый.
  Длина и размер не важны: скрипт сам обрежет его или чуть замедлит и подгонит под 1080×1920.
  Затем запустите `python3 4_build.py`.
- **Перерисовать кодом:** поправьте нужную сцену в `animation.html` (функции `scene1` … `scene6`),
  затем `node render_animation.js --scene 4` и `python3 4_build.py`.

## Как поменять одну фразу озвучки

Исправьте `text` фразы в `project.json`. В `subtitles` поправьте то же самое: блоки разделяются знаком `|`.
Затем запустите:
```bash
python3 1_voiceover.py      # переозвучит ТОЛЬКО изменённую фразу
python3 2_plan_scenes.py
python3 4_build.py
```
Переозвучить фразу без правки текста: `python3 1_voiceover.py --redo 4`.
