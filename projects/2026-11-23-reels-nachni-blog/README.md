# Reels «Начни блог» — CGI-кино

Вертикальный ролик 9:16, 1080×1920, ~29 сек. Голос: Gleb (ElevenLabs, eleven_multilingual_v2).

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `project.json` | **Главный файл для правок**: текст фраз, голос, промпты сцен, субтитры, громкость музыки |
| `audio/voiceover.mp3` | Готовая озвучка (послушать) |
| `audio/phrases/` | Озвучка по фразам. Уже оплачена, не удалять |
| `scenes/` | Клипы сцен: `scene_01.mp4` … `scene_06.mp4` |
| `music/` | Положите сюда **один** mp3/wav с фоновой музыкой, и она добавится сама |
| `reels_preview.mp4` | Превью с заглушками вместо сцен, которых ещё нет |
| `reels_final.mp4` | Финальный ролик (появится, когда будут все 6 клипов) |
| `voiceover.md`, `edit-plan.md`, `subtitles.srt` | Таблицы таймингов, монтажный план, субтитры |
| `.env` | Ваши ключи (в GitHub не попадает) |

## Ключи: файл `.env`

1. Скопируйте файл `.env.example` и назовите копию `.env` (с точкой в начале).
2. Откройте `.env` в любом текстовом редакторе.
3. Вставьте ключ после знака `=`, без пробелов и кавычек:
   ```
   ELEVENLABS_API_KEY=sk_ваш_ключ
   ```
   Где взять: elevenlabs.io → раздел Developers → API Keys → Create API Key.

## Как запустить на своём компьютере

Нужны Python 3.10+ и ffmpeg (Mac: `brew install ffmpeg`, Windows: `winget install ffmpeg`).
На Windows вместо `python3` пишите `python`.

```bash
pip install -r requirements.txt     # один раз
python3 1_voiceover.py              # ПЛАТНО: озвучка (спросит подтверждение)
python3 2_plan_scenes.py            # бесплатно: длина сцен под озвучку
python3 3_generate_scenes.py        # ПЛАТНО: видео (появится после выбора сервиса)
python3 4_build.py                  # бесплатно: склейка, субтитры, музыка
```

## Сцена 2 — 3D-анимация кодом (бесплатно)

Сцена 2 («Час? Два?») — 3D-часы по референсу, сделаны кодом, без платного видеосервиса.

- **Посмотреть:** откройте `animation.html` двойным щелчком в Chrome. Кнопка «↺ С начала» или клавиша R перезапускают анимацию.
- **Поменять цвета и тайминги:** блок `CFG` в начале `animation.html` (цвет обода, моменты «Час?» и «Два?» и т.д.).
- **Перезаписать в видео:** `node render_animation.js`. Файл появится в `scenes/scene_02.mp4` (~2 мин).
  Нужны Node.js и Playwright: `npm install playwright && npx playwright install chromium`.
- Затем `python3 4_build.py`.

## Как поменять одну сцену

- **Своим клипом:** положите файл в `scenes/` под именем `scene_04.mp4`, заменив старый.
  Длина и размер не важны: скрипт сам обрежет его или чуть замедлит и подгонит под 1080×1920.
  Затем запустите `python3 4_build.py`.
- **Новой генерацией:** исправьте `prompt` нужной сцены в `project.json`, затем
  `python3 3_generate_scenes.py --scene 4` (платно, только одна сцена) и `python3 4_build.py`.

## Как поменять одну фразу озвучки

Исправьте `text` фразы в `project.json`. В `subtitles` поправьте то же самое: блоки разделяются знаком `|`.
Затем запустите:
```bash
python3 1_voiceover.py      # переозвучит ТОЛЬКО изменённую фразу
python3 2_plan_scenes.py
python3 4_build.py
```
Переозвучить фразу без правки текста: `python3 1_voiceover.py --redo 4`.
