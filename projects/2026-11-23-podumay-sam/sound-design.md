Все файлы — `public/audio/`, сгенерированы ElevenLabs и нормализованы по EBU R128
(голос −16 LUFS, SFX −20 LUFS, музыка −16 LUFS). Длительность и темп не менялись.

## Озвучка

Громкость 1.0. Сцена 1 — шёпот (Gleb), сцены 2–6 — диктор VASKO. Старт реплики = начало сцены + смещение: С1 +2, С2 0, С3 +20, С4 +4, С5 +6, С6 +6 кадров.

## Музыка (`music.mp3`, ElevenLabs Music, `music_v1`, composition plan 40 c)

В самом треке динамика почти ровная (≈ −17 dB RMS с 2-й по 33-ю секунду, затухание с 34-й).
Драматургию делает автоматизация громкости в `src/timeline.ts → musicVolume()`:

| Кадры | Громкость | Смысл |
|---|---|---|
| 0–20 | 0 → 0.15 | вход |
| 20–390 | 0.15 → 0.25 | нарастание к сцене 3 |
| 390–560 | 0.25 | пик (толпа) |
| 560–604 | 0.25 → 0 | **пауза перед фактом 2** |
| 604–660 | 0 → 0.18 | сдержанное возвращение |
| 660–990 | 0.18–0.20 | факт 2, поворот |
| 990–1196 | 0.20 → 0 | спад в финале |

Под речью громкость множится на 0.6 (рампы 10/12 кадров). Интервалы речи берутся из пословных
таймкодов forced alignment.
