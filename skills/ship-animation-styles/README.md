# ship-animation-styles

Claude Code skill: один корабль в 10 стилях анимации (пиксель-арт, мел, светящийся скетч, PS2, комикс, плоский вектор, линии на чёрном, кино-CGI, конструктор, игрушечное 3D).

## Установка

Скопируйте папку в каталог скиллов Claude Code:

- Windows: `%USERPROFILE%\.claude\skills\ship-animation-styles`
- macOS / Linux: `~/.claude/skills/ship-animation-styles`

## Состав

- `SKILL.md` — описание скилла и таблица стилей
- `styles/` — 10 HTML-шаблонов, по одному на стиль
