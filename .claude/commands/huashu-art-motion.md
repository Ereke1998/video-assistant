# Huashu Art Motion — движущиеся картины в стилях

Входные данные: $ARGUMENTS

## Задача

Сделай короткую движущуюся картину (пейзаж, сцену, натюрморт) в выбранном художественном стиле и опиши киношный переход к следующей картине.

## Правила

1. **Стиль задаёт и цвет, и линию.** Для восточной живописи тушью — монохром с акцентом одного цвета (например, красной печати); для акварели — прозрачные слои и «воздух».
2. **Движение в картине — тонкое:** облака, туман, рябь воды, колыхание травы, одна движущаяся деталь (лодка, птица). Не больше двух движущихся элементов.
3. **Кадр 16:9 или 9:16** — оставь в верхней трети пространство под заголовок.
4. **Переход между картинами:** затемнение через туман, «размыв» штриха, наезд камеры в деталь; один тип перехода на ролик.
5. **Иероглифы и надписи** — только если пользователь их запросил; проверяй смысл перед использованием.

## Формат вывода

```

Стиль: <один из 36> | Формат: 16:9 / 9:16 | Длительность: XX с

## Сцена
- Композиция: ...
- Движущиеся элементы: ...

## Переход
- Тип: ... | Длительность: X с

## Промпт / код
<промпт (EN) или фрагмент кода для рендера>
```
