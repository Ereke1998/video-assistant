# Правка ролика

Входные данные: $ARGUMENTS

1. Определи сцену: по смыслу («хук», «CTA») или по таймкоду через `build/timeline.json` (start ≤ N < end).
2. Найди параметр по словарю в `edits.md` проекта; если его нет — правь компонент в `graphics/`.
3. Меняй **только** затронутый параметр. Текст и плашки не выходят из safe zone (`format.safe_zone`).
4. Добавь строку в `edits.md`: запрос → ключ → было → стало.
5. Перегенерируй минимум (колонка «Перегенерировать» в словаре): текст сцены/голос → с `voiceover.py`; субтитры → `subtitles.py`; визуал/тема/звук → только `sync_remotion.py` + рендер.
6. Ответ: одна таблица «было → стало» + путь рендера.
