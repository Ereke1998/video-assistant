# Правка ролика

Входные данные: $ARGUMENTS

1. Определи блок `timeline` по таймкоду или смыслу («хук», «CTA», «на 5 секунде» → блок, где start ≤ 00:05 < end).
2. Найди параметр по словарю в `edits.md` проекта; если его нет — правь код композиции в `graphics/`.
3. Меняй **только** затронутый параметр. Тексты/субтитры не выходят из safe zone (`format.safe_zone`).
4. Добавь строку в `edits.md`: запрос → файл/ключ → было → стало.
5. Перерендери только нужное: правка `autocut` → весь конвейер; `subtitles` → `subtitles.py` + рендер; `timeline`/`graphics` → только рендер.
6. Ответ: одна таблица «было → стало» + команда/путь рендера.
