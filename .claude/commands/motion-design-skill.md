# Motion Design Skill — темп и easing

Входные данные: $ARGUMENTS

## Задача

Подбери тайминг и кривые скорости (easing) для движения элементов в ролике, чтобы анимация выглядела естественно и дорого.

## Правила

1. **Ease-out для появления** — элемент быстро входит и мягко останавливается.
2. **Ease-in для ухода** — элемент медленно начинает и быстро уходит.
3. **Ease-in-out для переходов** между состояниями на экране.
4. **Overshoot / back** — только для игривых элементов (кнопки, иконки, стикеры), не для текста.
5. **Длительность:** микро-акцент 0,15–0,3 с; появление текста 0,4–0,6 с; смена сцены 0,5–0,8 с.
6. **Задержка (stagger)** между элементами 0,05–0,1 с; больше — ощущается как тормоз.
7. **Кривые cubic-bezier** указывай явно, например `cubic-bezier(0.22, 1, 0.36, 1)` для мягкого выхода.

## Формат вывода

```
# Тайминг: <название>

| Элемент | Действие | Длительность | Easing | Задержка |
|---------|----------|--------------|--------|----------|
| Заголовок | появление снизу | 0.5 с | ease-out (cubic-bezier …) | 0 |

```
