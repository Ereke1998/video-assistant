# Manim Skill — обучающие математические анимации

Входные данные: $ARGUMENTS

## Задача

Разбей объяснение на сцены и напиши код для библиотеки Manim (Community Edition), которая рисует объяснительные анимации в стиле 3Blue1Brown.

## Правила

1. **Один вопрос — одна сцена.** Сначала ставь задачу («почему…?»), потом показывай визуализацию, потом вывод.
2. **Порядок:** формула или вопрос → геометрическая или визуальная модель → преобразование → итог.
3. **Цвета:** одна формула — одна цветовая схема; один и тот же объект всегда одного цвета.
4. **Текст и формулы** через `MathTex`/`Tex`, объекты появляются через `Write`, `Create`, `FadeIn`; переходы через `Transform`.
5. **Вертикаль 9:16:** в Manim задай `config.pixel_width = 1080`, `config.pixel_height = 1920`, `config.frame_width` соответственно, и держи объекты в центре.
6. **Рендер:** укажи команду, например `manim -pqh scene.py ConceptScene` (качество `-qh` — 1080p).
