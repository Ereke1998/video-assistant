# JavaScript Animation Skill — анимация на коде

Входные данные: $ARGUMENTS

## Задача

Напиши самодостаточную HTML-страницу с анимацией (и при необходимости звуком на Web Audio), которую можно записать экраном или через инструмент записи в видео.

## Правила

1. **Один файл:** HTML + CSS + JS в одном документе, без внешних зависимостей, если не запрошено иное.
2. **Время — через `requestAnimationFrame` и единый таймлайн** (`t` в секундах), а не через `setInterval`, чтобы кадры были предсказуемы при записи.
3. **Easing** — стандартные функции (`easeOutCubic`, `easeInOutQuad`), см. правила тайминга.
4. **Фиксированный размер 1080×1920** (или 1080×1080) и кнопка/параметр для перезапуска с `t = 0`.
5. **Звук (если нужен):** Web Audio API, сгенерированные осцилляторы и огибающие; громкость не выше −6 dB пика.
6. **Запись:** укажи, как записать (экранная запись в 60 fps или скрипт с покадровым рендером).
