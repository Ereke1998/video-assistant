# Субтитры для Reels / TikTok

Входные данные: $ARGUMENTS

## Задача

Разбей текст или транскрипт на короткие экранные субтитры для вертикального видео 9:16.
Язык — язык исходного текста (**казахский** или **русский**), не переводи без запроса.

## Правила

1. **3–5 слов на экран**, максимум 1–2 строки. Не разрывай устойчивые сочетания, предлог держи вместе со словом.
2. **Длительность показа:** 0,8–2,5 с на экран; смена — синхронно с речью.
3. **Выделение смыслов:** в каждом экране отметь 1 ключевое слово `**СЛОВО**` (капс/цвет/увеличение при монтаже). Цифры, выгоды, эмоции, призывы — в приоритете.
4. **Хук:** первый экран (0–2 с) — самый сильный, допускается отдельный стиль.
5. **Чистка:** убирай слова-паразиты, повторы, «э-э», «ну»; смысл не меняй.
6. **Пунктуация:** минимальная — без точек в конце, допустимы `?` и `!`.
7. **Эмодзи** — только по запросу, не более 1 на экран.
8. **Безопасная зона:** текст в центральной части кадра, выше нижних ~20% (интерфейс платформы).

## Формат вывода

```
# Субтитры: <название>
Язык: RU / KZ | Экранов: XX | Длительность: XX с

| # | Начало | Конец | Текст | Акцент |
|---|--------|-------|-------|--------|
| 1 | 00:00.00 | 00:01.40 | Ты делаешь **ЭТО** неправильно | ЭТО |
| 2 | ... | ... | ... | ... |

## Рекомендации по стилю
- Шрифт / размер / цвет акцента / анимация появления (pop, typewriter, scale)
```

Если пользователь просит файл для монтажки — дополнительно выдай `.srt`:

```
1
00:00:00,000 --> 00:00:01,400
Ты делаешь ЭТО неправильно
```
