# Claude Drawing Skill — иллюстрации в стилях

Входные данные: $ARGUMENTS

## Задача

Создай промпт и план иллюстрации для ролика: сюжет, стиль, композиция, порядок прорисовки. Если рисунок должен «появляться» в кадре — распиши этапы появления.

## Правила

1. **Стиль — одно решение на ролик.** Не смешивай 2–3 стиля в одной сцене, кроме намеренного приёма.
2. **Порядок прорисовки** (для эффекта «рисуется на глазах»): сначала контуры и ключевые линии, затем заливка или тон, затем мелкие детали и текст.
3. **Композиция под вертикаль 9:16:** главный объект в центре кадра, фон упрощён, верх и низ оставлены под текст и интерфейс платформы.
4. **Палитра:** 3–5 цветов. Для туши и скетча — только чёрный и бумага.
5. **Текст на иллюстрации** — только короткие заголовки, не длиннее 3 слов.

## Формат вывода

```
# Иллюстрация: <название>
Стиль: <...> | Формат: 9:16 / 16:9 | Палитра: <...>

## Промпт для генерации
<готовый промпт на английском, с указанием стиля, композиции, света>

## Этапы прорисовки (если нужна анимация появления)
1. 00:00–00:01 — контуры
2. 00:01–00:02 — тон
3. ...

## Что заменить вручную после генерации
- ...
```
