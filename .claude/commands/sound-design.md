# Саунд-дизайн и подбор аудиоэффектов

Входные данные: $ARGUMENTS

## Задача

По сценарию, монтажному плану или описанию ролика составь полную звуковую партитуру: где и какой звук стоит, зачем он нужен и с какой громкостью.
Отвечай на языке пользователя (**казахский** или **русский**); названия эффектов можно оставлять на английском.

## Что расписать

### 1. Фоновая музыка
- **Стиль/жанр** (lo-fi, trap, cinematic, corporate, phonk, ethno/домбыра и т.д.).
- **Темп** — BPM; совпадение монтажных склеек с долями.
- **Настроение** и его изменение по ходу ролика (интро → нарастание → кульминация → финал).
- **Структура:** где вход, дроп, стоп-музыки (music stop), аутро.
- Ключевые слова для поиска в стоках (Artlist, Epidemic Sound, YouTube Audio Library и т.п.).

### 2. SFX — точки появления
| Эффект | Где использовать |
|---|---|
| **whoosh / swoosh** | переходы, быстрые движения камеры, вылет текста |
| **pop / click** | появление субтитров, иконок, стикеров |
| **riser** | нарастание перед раскрытием, перед дропом |
| **impact / hit / boom** | кульминация, смена сцены, ключевая цифра |
| **glitch / swipe / ding / cash** | по смыслу кадра |
| **reverse / downlifter** | выход из напряжения, затемнение |

Правило: riser заканчивается ровно в точке impact; SFX не перекрывают ключевые слова диктора.

### 3. Атмосферы (ambience / room tone)
- Фон локации: город, офис, природа, кафе, ветер, толпа.
- Room tone под чистую речь, чтобы склейки не «проваливались».

### 4. Сведение (ориентиры)
- Голос: пик около −6 dBFS, итог ролика −14 LUFS (соцсети), True Peak ≤ −1 dBTP.
- Музыка под голосом: −18…−24 dB относительно голоса, сайдчейн/дакинг.
- SFX: −10…−18 dB, акцентные impact — громче.
- Атмосферы: −25…−35 dB.

## Формат вывода

```
# Саунд-дизайн: <название>
Длительность: XX с | Музыка: <жанр>, XX BPM, <настроение>

## Звуковая партитура
| Таймкод | Событие в кадре | Музыка | SFX | Атмосфера | Громкость / заметки |
|---------|-----------------|--------|-----|-----------|---------------------|
| 00:00 | Хук, вылет заголовка | вход, фильтр | whoosh + pop | — | SFX −12 dB |
| 00:04 | Раскрытие | дроп | riser → impact | — | impact −8 dB |

## Музыка
- Стиль, темп, настроение, структура, поисковые теги

## Список SFX для скачивания
- whoosh_fast ×3, pop_soft ×8, riser_4s ×1, impact_deep ×2 ...

## Советы по сведению
- ...
```

## Автоматизация

В проектах конвейера звук собирается кодом: `python3 pipeline/sound.py` расставляет SFX по анимациям, синтезирует музыку, сводит и пишет `sound-design.md`. Ручную партитуру используй для правок и нестандартных роликов.
