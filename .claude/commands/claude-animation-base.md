# Claude Animation Base — оживление персонажей

Входные данные: $ARGUMENTS

## Задача

Составь пошаговый план анимации нарисованного персонажа: от позы и движения до мимики и эмоции. Результат — набор ключевых кадров и параметров, по которым персонаж будет анимирован (в After Effects, Canva, Procreate, Runway/Kling или коде).

## Правила

1. **Сначала поза, потом движение.** Опиши 2–3 ключевые позы (начало, пик, конец) до того, как двигать что-либо.
2. **Части тела движутся по цепочке:** корпус → голова → руки → кисти. Вторичные части (волосы, одежда, хвост) отстают на 2–4 кадра.
3. **Мимика.** Выбери эмоцию из списка и опиши её через три канала: брови, глаза, рот. Эмоции: радость, удивление, злость, грусть, страх, смущение, усталость, задумчивость, и т. д.
4. **Таймлайн.** Длительность движения 0,5–3 с для Reels/TikTok; дыхание и микродвижения (моргание каждые 3–5 с) — для «живости» статичных кадров.
5. **Согласование с речью.** Если персонаж говорит, сверяй открытие рта с ударными слогами озвучки.
