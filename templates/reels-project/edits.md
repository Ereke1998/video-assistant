# Журнал правок

Каждая правка пользователя («сделай хук крупнее», «ускорь динамику на 5 секунде») фиксируется здесь
и вносится точечно в `project.config.json` (или в код композиции, если параметра нет в конфиге).

| # | Дата | Запрос (как сказал пользователь) | Что изменено | Файл / ключ | Было → Стало |
|---|---|---|---|---|---|
| 1 | | | | | |

## Словарь правок → параметры

| Формулировка | Куда | Действие |
|---|---|---|
| «хук крупнее / мельче» | `timeline[hook].graphics.props.scale` | ×1.2 / ×0.85 |
| «ускорь / замедли на N сек» | `timeline[блок с N].speed` | 1.0 → 1.15–1.3 / 0.85 |
| «больше динамики» | `autocut.min_silence_sec`, `keep_padding_sec` | уменьшить (0.35 → 0.25, 0.08 → 0.05) |
| «субтитры крупнее / ниже» | `subtitles.style.size_px` / `position_y_pct` | ±10% / ±4 п.п. (не выходить из safe zone) |
| «меньше слов на экране» | `subtitles.words_per_block.max` | 4 → 3 |
| «выдели слово X» | `subtitles.keywords` | добавить X |
| «зум на экран» | `timeline[блок].zoom` | enabled: true, factor 1.2–1.4 |
| «музыка тише» | `audio.music.volume_db` | −3 dB |
| «добавь звук на N сек» | `timeline[блок].sfx` | добавить whoosh/pop/riser/impact |
